## 🛡️ My Approach

I believe that cybersecurity requires more than running tools. It requires understanding the technology, verifying results, explaining risks, and recommending practical defenses.

I perform security testing only on systems and networks I own or have explicit permission to assess. I do not publish passwords, tokens, private keys, or confidential information.
